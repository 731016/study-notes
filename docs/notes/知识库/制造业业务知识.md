## ERP
```
ERP协同生产管理系统实现产销财一体化管控：
 
销售管理：订单与预测双模式需求入口
 
计划管理：MRP引擎基于BOM+工艺倒排计划，自动计算物料净需求
 
采购管理：按MRP建议生成采购订单，跟踪到货与结算
 
生产管理：工单下发、领料控制、进度跟踪与完工入库
 
库存管理：多仓库实时管控，支持安全库存预警
 
财务管理：存货核算、成本归集与应收应付联动
```
销售管理:承接客户订单与市场需求预测，作为整个系统的需求源头；

计划管理:以MRP引擎为核心，基于BOM多级展开与生产工艺路线，通过提前期倒排自动平衡库存、在制、在购资源，精准计算零部件及外购料的净需求，生成可执行的采购与生产计划；

采购管理:依据MRP建议自动下达采购订单，跟踪供应商交货与质量检验；

生产管理:按工单组织领料、工序流转与完工入库，实时反馈进度异常；库存管理实现多仓库、多批次精细化管控，动态预警安全库存与呆滞物料；

财务管理:自动归集采购、生产、销售环节的成本与应收应付数据，保障账实一致与利润精准核算。

### MRP核心逻辑

MRP（Material Requirements Planning，物料需求计划）是一种生产管理和库存控制系统，用于制造业中确定生产所需的原材料、零部件和组件的需求量和需求时间。

"从客户需求出发，按产品结构拆解，考虑现有资源，倒排时间节点，精准计算缺什么、缺多少、何时到位。"



![image-20260404212614778](https://note-1259190304.cos.ap-chengdu.myqcloud.com/noteimage-20260404212614778.png)



一、时间主线 + 倒推逻辑
```
销售订单交货期 ──→ 成品装配 ──→ 零部件加工 ──→ 原材料采购
    ↑_________________________________________________|
                    （按提前期倒推）
```

**核心思想**：从"交货 deadline"倒推，每个环节需要提前多久开始，才能保证最终按时交付。

![image-20260404213757936](https://note-1259190304.cos.ap-chengdu.myqcloud.com/noteimage-20260404213757936.png)



二、以 BOM 结构和生产工艺为依据
层级	示例（生产一台电脑）	
Level 0	成品电脑（销售订单对象）	
Level 1	机箱、主板、显示器、电源（自制件/外购件）	
Level 2	主板上的芯片、电容、插槽（原材料）	

**BOM 展开**：MRP 逐层拆解，计算每一层物料的需求量和需求时间。
生产工艺：考虑每道工序的加工时间、顺序、产能约束。



三、以销售订单（或预测）为源头
需求来源	适用场景	
销售订单	按单生产（MTO），客户已下单	
销售预测	备货生产（MTS），基于市场需求预测	

毛需求 = 订单数量（或预测数量）



四、平衡库存、在制、在购
`净需求 = 毛需求 - 现有库存 - 在途订单 + 安全库存 + 已分配量`

项目	含义	作用	
库存	仓库里现有的	直接可用，减少新需求	
在制	车间正在生产的	即将入库，减少新需求	
在购	已下单未到货的	即将到货，减少新需求

避免重复采购/生产，这是 MRP 的核心价值之一。



五、通过提前期倒推，生成净需求计划
```
交货期：4月30日
├── 成品装配提前期：3天 → 4月27日开始装配
├── 零部件加工提前期：5天 → 4月22日开始加工
└── 原材料采购提前期：10天 → 4月12日下达采购单
```

计划产出：

生产计划：何时开工、生产多少、哪条产线

采购计划：何时下单、采购多少、供应商是谁



六、保证及时配套和按期交付
目标	MRP 如何实现	
及时配套	所有物料按同一时间到达，避免"料等人"或"人等料"	
按期交付	倒排计划确保每个环节不延误	
降低库存	按需采购，减少资金占用	



## MES
生产制造执行系统

MES是连接ERP与底层自动化设备的桥梁，负责将生产计划转化为车间可执行的生产任务，并实时监控执行过程。

### 流程制造MES（烟草行业示例）

适用于食品饮料、化工、药品、烟草等连续生产行业，成品是连续物料，不可拆分。

#### 生产工单
车间人员下发生产指令到底层数采系统（信息包括牌号等信息），数采系统解析后返回工单号，机台，批次等信息，mes生成生产工单；

产量分为数采产量和车间人员填写的实际的产量，可能有抽检或其他用途和数采系统有出入

工单状态通过数采系统反馈

由车间人员通过每个牌号的产量确认单填写，可能有各个工序的不同的数量

#### 出入库
生产牌号需要的物料的库存管理，主要负责专注于物料从收货->检验->出库投入生产这个流程的控制 收货需要创建在MES创建入库单，由WMS物流管理平台发送数据到MES，进行收货；MES校验货物信息（货物数量）后，根据物料的检验标准创建报检单进行抽检，抽检合格后入库

#### 检验工单
通过维护牌号工艺标准或生产牌号的原料的检验信息，如烟丝的烘丝温度，接装纸的抗张拉力强度

通过生产工单和检验标准创建检验工单进行检验，现场使用检查仪器，数采数据通过开发的net桌面程序，通过udp、tcp、opc、串口通信上传至检验工单

#### 数据采集
监控数采数据，计算CPK,PPK..质量参数，生成监控图形

通过创建的工艺标准下发的数采底层系统，PLC通过OPC协议上传至Wonderware数据库，包含牌号，批次，工单号等信息

通过kafka采集Wonderware数据库的实时数据，并处理计算需要的数据，通过websocket推送至前台展示实时监控图形

#### 生产流程

用户负责对成品烟进行排产，排出生产计划，计划导入mes系统，具体到机台，这个机台今天生产多少箱烟

一个新的牌号

牌号基础信息由中烟主数据下发

用户在mes系统维护牌号的工艺信息（制丝、卷包的质量参数、工序信息下发到底层集控系统），这些信息会在数采时使用

用户下发生产指令单（牌号等信息）给底层集控系统，交互使用中间表交互，集控解析信息后返回生产工单信息（包括班次，开始结束时间，牌号，批次，工单号等），生产工单的生产状态（下发PLC，开工，完成）由集控系统通过接口返回

产量由产量确认单提供，绑定到工单，部分信息（数采产量）由底层系统提供，部分由用户填写，完工时会走审批流程手动确认

生产用到的材料通过出入库记录来绑定工单号

物料入库，入库单由WMS接口提供，可能一个单据有多个材料，收货后对应明细都会生成一条单据

收货时，生成材料检验单，提交后会生成检验工单，这里没有堵死，只是记录一个流程，这里收货后单据状态就是完全收货了

这里的物料检验由实验室完成，通过tcp、ucp、opc、串口传输到mes系统的检验工单明细

生产消耗

每个机台用了多少材料信息由WMS提供，只有总的材料量；没有记录如果这个机台有多的材料借给别的机台用了，通过用户手动录入，mes再班次结束是自动汇总计算

### 离散制造MES（机械/电子行业示例）

适用于机械、家电、五金、电子设备等行业，产品由多个零部件组成，可拆解，工序离散、可跳转。

#### 核心业务模块

**1. 主数据管理（MD）**

- **物料管理（MdItem）**: 物料/产品编码、名称、规格型号、单位、安全库存、批次管理、库存上限下限、是否允许负库存
- **BOM管理（MdBom）**: 多级BOM结构（头记录+行记录）、版本控制、用量、损耗率、BOM变更记录
- **客户管理（MdClient）**: 客户编码、名称、简称
- **供应商管理（MdVendor）**: 供应商编码、名称、简称
- **车间管理（MdWorkshop）**: 车间编码、名称

**2. 生产管理（Pro）**

- **生产工单（ProWorkorder）**: 工单类型、订单来源、产品信息、数量、批次、客户/供应商、需求日期、工艺路线、已生产数量、状态
- **工艺路线（ProRoute）**: 路线编号、名称、画布JSON数据（可视化流程）、是否启用
- **工序定义（ProProcess）**: 工序编码、名称、注意事项、是否启用
- **生产任务（ProTask）**: 关联工单、工作站、工序、排产数量、已生产数量、合格/不合格数量、报工管理、开始/结束时间、实际开工时间、甘特图颜色
- **工序流转卡（ProCard）**: 绑定工单、批次、流转数量、状态、赋码地址、当前工作站

**3. 质量管理（QC）**

- **来料检验（QcIqc）**: 供应商信息、物料信息、接收数量、检测数量、合格/不合格数、缺陷率（致命/严重/轻微）、检验模板、来源单据
- **过程检验（QcIpqc）**: 关联工单/任务/工作站/工序、检测数量、合格/不合格数、缺陷分类、检验结果
- **出货检验（QcOqc）**: 客户信息、批次、发货数量、检测数量、合格/不合格数、出货日期
- **退货检验（QcRqc）**: 退货检验单管理
- **缺陷管理（QcDefect）**: 缺陷类型定义、缺陷记录
- **检验指标（QcIndex）**: 检验指标定义

**4. 仓储管理（WM）**

- **条码管理（WmBarcode）**: 条码生成、条码配置
- **批次管理（WmBatch）**: 批次追踪
- **序列号管理（WmSn）**: 产品序列号追溯
- **生产领料（WmIssue）**: 工单领料、发料明细
- **生产退料（WmRtIssue）**: 退料单、退料类型、关联工单/工作站
- **产品入库（WmProductRecpt）**: 成品入库
- **销售出库（WmRtSales）**: 销售发货
- **调拨管理（WmTransfer）**: 仓库间调拨
- **库存盘点（WmStockTaking）**: 盘点任务、盘点结果

**5. 设备管理（DV）**

- **设备管理（DvMachinery）**: 设备编码、名称、品牌、规格、类型、所属车间、最近保养/点检时间、设备状态
- **设备维修（DvRepair）**: 维修记录、维修明细
- **点检管理（DvSubject）**: 点检项目、点检计划、点检记录
- **保养记录（DvMaintenRecord）**: 设备保养历史

**6. 工装夹具管理（TM）**

- **工装夹具（TmTool）**: 编码、名称、品牌、型号、类型、数量、可用数量、保养周期、下次保养日期、状态
- **夹具类型（TmToolType）**: 夹具分类管理

**7. 排班管理（Cal）**

- **排班计划（CalPlan）**: 计划编号、名称、开始/结束日期、轮班方式、倒班方式、班次数量、状态
- **班次定义（CalShift）**: 班次时间定义
- **班组管理（CalTeam）**: 班组人员配置

**8. 数据采集（IoT）**

- **PLC数据采集（PlcData）**: 实时采集设备数据
- **安灯系统（Andon）**: 安灯配置、安灯记录
- **OEE监控**: 设备综合效率计算与监控

#### 生产流程

1. **订单导入**: 销售订单或预测计划导入MES，生成生产工单
2. **工单创建**: 指定产品、数量、工艺路线、客户、需求日期
3. **任务派工**: 根据工艺路线自动生成各工序生产任务，分配到具体工作站
4. **扫码报工**: 工人通过PDA扫码开始执行任务，记录实际开工时间
5. **过程检验**: 关键工序自动触发过程检验单（IPQC）
6. **工序流转**: 通过流转卡（ProCard）跟踪物料在各工序间的流转
7. **完工入库**: 最后一道工序完成后，产品入库
8. **出货检验**: 发货前进行出货检验（OQC）
9. **销售出库**: 检验合格后安排发货

#### 核心特点

- **BOM管理**: 多级物料清单，支持版本控制和损耗率计算
- **工艺路线**: 可视化配置工序流程，支持并行和串行工序
- **工单派工**: 任务精确分配到工作站/设备/人员
- **进度追踪**: 实时跟踪每个工单、任务的完成进度
- **序列号追溯**: 支持单品级追溯（WmSn）
- **质量三检**: 来料检验（IQC）、过程检验（IPQC）、出货检验（OQC）
- **设备管理**: 设备台账、保养、维修、点检一体化管理
- **工装夹具**: 夹具生命周期管理、可用性跟踪


### 流程制造 vs 离散制造对比

| 特性 | 流程制造 | 离散制造 |
|------|----------|----------|
| **行业示例** | 食品饮料、化工、药品、烟草、油漆涂料 | 机械、家电、五金、电子设备 |
| **产品形态** | 连续物料，不可拆分 | 由多个零部件组成，可拆解 |
| **生产方式** | 流程连续、不可中断，多为流水线 | 工序离散、可跳转，多为工单制 |
| **核心管理** | 配方管理、批次追溯、质量实时监控 | BOM管理、工艺路线、工单派工 |
| **产量管理** | 数采产量为主，人工确认补充 | 报工数量、合格/不合格数量统计 |
| **物料追溯** | 批次级追溯 | 序列号级追溯（单品级） |
| **设备管理** | PLC集成、实时数据采集 | 设备台账、保养维修点检 |
| **典型MES功能** | 牌号管理、工艺标准下发、实时监控图形 | 工序流转卡、生产任务管理、甘特图排程 |

### 流程制造核心要点

**（1）配方管理**：精确控制原材料比例、工艺参数，如烟草行业的制丝温度、接装纸规格

**（2）批次管理**：完整追溯每个批次的生产时间、使用的原材料批次、生产设备、操作人员

**（3）质量控制**：实时监控生产过程质量数据（如CPK、PPK参数），通过OPC协议采集PLC数据

### 离散制造核心要点

**（1）BOM管理**：多级物料清单，支持版本控制和损耗率计算，精确知道产品需要哪些零件

**（2）工艺路线**：可视化配置工序流程，定义每道工序、执行车间、预计工时，支持并行和串行

**（3）工单派工**：将生产任务精确分配到工作站、设备或员工，支持扫码报工

**（4）进度追踪**：实时跟踪每个工单、任务的完成进度，通过甘特图直观展示排程情况
